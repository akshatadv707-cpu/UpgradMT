# Part 1 challenge — Put React together

Build a small dashboard: **UserCard** (props) + **Counter** (useState) + **PostList** (useEffect with loading and error). Use TypeScript types.

## Solution files

| File in this folder | Save as in your app |
|---------------------|---------------------|
| `01-user-card.tsx` | `app/components/UserCard.tsx` |
| `02-post-list.tsx` | `app/components/PostList.tsx` |
| `03-counter.tsx` | `app/components/Counter.tsx` |
| `challenge-page.tsx` | **`app/page.tsx`** (replace whole file) |

## What you should see

- Two user cards (Alice, Bob)
- A counter button that increments on click
- "Loading..." then a list of post titles (or an error message if fetch fails)
